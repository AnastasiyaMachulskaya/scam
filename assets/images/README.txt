Здесь можно разместить локальные изображения:

  cats.gif    — GIF с танцующими котиками
               (замените URL в style.css → блок .bg → background-image)

  bun100.png  — изображение купюры "100 БУН" (опционально)
               (раскомментируйте <img> в index.html внутри .banknote)

  envelope.png — изображение конверта (опционально, если хотите
                 заменить CSS-конверт на картинку)
